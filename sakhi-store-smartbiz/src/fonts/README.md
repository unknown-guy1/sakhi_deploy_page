# Astoria Font Setup Instructions

## Download the Astoria Font

The Astoria font needs to be downloaded manually from one of these sources:

1. **Dafont**: https://www.dafont.com/astoria.font
2. **Exfont**: https://exfont.com/astoria.font
3. **Creative Fabrica**: https://www.creativefabrica.com/product/astoria/

## Installation Steps

1. Download the font ZIP file from one of the sources above
2. Extract the ZIP file
3. Copy the following font files to this `fonts` folder:
   - `Astoria-Regular.ttf` (or `Astoria.ttf`)
   - `Astoria-Bold.ttf` (if available, for bold weight)

## File Naming

Make sure the files are named exactly as follows:
- `Astoria-Regular.ttf` (for normal weight)
- `Astoria-Bold.ttf` (for bold weight - optional)

If you only have `Astoria.ttf`, you can rename it to `Astoria-Regular.ttf` or update the CSS `@font-face` declarations accordingly.

## After Adding Font Files

Once the font files are in this folder, the CSS will automatically load them and the "SmartBiz" text will display using the Astoria font.

## Alternative: Using Web Fonts

If you prefer not to host the font files, you can:
1. Use a font hosting service like Google Fonts (if Astoria becomes available)
2. Use a similar modern font that's available on Google Fonts
3. Convert the font to web formats (WOFF/WOFF2) for better performance
